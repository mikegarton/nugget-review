Channel economics — lifetime

Cost = Claude tokens + prorated Supadata credits, from the call log. Nugget counts are surviving nuggets (1★ rows are purged). Disabled channels are campaign discoveries, not part of the trusted poll list. Value rates are per-dollar — nug/$ and 5★/$ — because substack costs run magnitudes below video costs and "nuggets per dollar" compares cleanly where "$0.00003 per nugget" reads as noise; bigger is better, like every density column. Substack transcript/minutes columns are legitimately blank; nug/item is the density metric both sources share. Channels processed before 2026-07-25 predate cost logging and show $0 (per-dollar rates blank). Tap a column header to sort.

Pipeline flow parameters

Every tunable number the pipeline runs on — batch pace, retry behavior, budgets, caps — live from the config table yt_params. Edit in the SQL editor — update yt_params set value = '…' where key = '…'; — and the next run picks it up, no redeploy. This table is the surface a future control GUI will edit.
