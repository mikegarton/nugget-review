Sending videos to the pipeline

Three ways to hand one specific video to the nugget pipeline. All three feed the same intake; pick whichever is nearest to hand.

Priority: the first 3 manual adds per hour (counted across all surfaces) jump to the front of the processing queue; the rest still run ahead of every automatic source. If nothing worth keeping is found, the video appears in the viewer's "your manual adds" strip — you asked, so the answer is shown either way.

Chrome extension desktop only

Install (once per computer)

  1. Get the folder extension\ from the nugget-review repo onto the computer (on the dev machine it's C:\dev\nugget-review\extension; elsewhere, Code → Download ZIP and unzip).
  2. In Chrome open chrome://extensions, switch on Developer mode (top right).
  3. Click Load unpacked and pick the extension folder.
  4. Click the extension's Details → Extension options and paste the review key (the same key as the nugget viewer bookmark — not the ops write key). Save.

Use

  • Alt+Q on any YouTube watch page sends that video. A notification confirms; ⚡ means it jumped the queue.
  • Right-click any YouTube link or thumbnail → "Send to nugget pipeline" — no need to open the video.
  • The badge on the extension icon counts today's adds.

Limitations

  • Desktop Chrome/Edge/Brave only — no extension support exists in mobile or TV Chrome, so this can never cover the Shield (that's the playlist's job).
  • The key is stored per browser profile; repeat step 4 on each machine.
  • Loaded unpacked, so Chrome may nag about developer-mode extensions and it won't auto-update — refresh the folder (git pull / re-download) to update.
  • If Alt+Q doesn't fire, another extension owns the shortcut — reassign at chrome://extensions/shortcuts.

Share sheet Android phone/tablet

Installs the control room as an app; "Nuggets" then appears in Android's share sheet, so the YouTube app's own Share button becomes the capture surface.

Set up (once per Android device)

  1. In Chrome on the phone, open the control room and make sure the review key is saved there (the viewer/ops links show when it is — the share handler uses the same saved key).
  2. Chrome menu (⋮) → Add to Home screen → Install. (If Chrome offers an "Install app" banner, that's the same thing.)

Use

  • In the YouTube app, on any video: Share → Nuggets. A page opens, sends it, and shows the verdict — ⚡ front of the queue, ✓ added, — already known. Two taps, ~5-minute latency.

Limitations

  • Android only — iOS Safari doesn't support web share targets (on an iPhone/iPad, use the playlist inbox instead).
  • The share sheet entry appears only after the install step; a plain bookmark isn't enough.
  • If the verdict page says "No review key on this device", do step 1 — key first, then share works.

Playlist inbox Shield · phone · tablet · any TV

One shared inbox playlist; saving any video to it from any device's YouTube app sends it to the pipeline on the next hourly sweep.

Set up (once)

  1. In YouTube (easiest on desktop): save any video to a new playlist named e.g. Nugget inbox, visibility Unlisted — this matters: a private playlist is invisible to the pipeline (reads as 404); unlisted is reachable but not discoverable.
  2. Open the playlist and copy its id from the URL — the part after list=, starting PL….
  3. In the Supabase SQL editor run:
    update yt_params set value = '<PL…>' where key = 'manual_playlist_id';

Use (every device)

  • NVIDIA Shield / TV YouTube app: on a video, open its options (long-press or the ⋮ menu) → Save → pick Nugget inbox.
  • Phone / tablet: under the video, Save → Nugget inbox.
  • That's it — the poller sweeps the playlist every hour.

Notes

  • Latency is up to an hour (poll-bound), vs ~5 minutes for the other two surfaces.
  • Videos stay in the playlist after ingestion — the pipeline never removes them (that would need OAuth). Clear it out whenever it annoys you; re-ingestion can't happen (re-adds are no-ops).
  • To pause the inbox: set manual_playlist_id back to '' in the SQL editor.

Paste box any browser

On the control room, once the review key is saved on that device: paste one or many YouTube links (one per line or comma-separated) and hit Send to pipeline. The reply lists each video — ⚡ jumped the queue, ✓ added, — already known.

This is the batch surface: up to 50 links at once. It works on a phone too — from the YouTube app: Share → Copy link → paste here.

Where results appear

  • Nuggets land in the viewer like everything else, with a manual add chip.
  • Manual adds that produced zero nuggets appear in a strip at the top of the viewer — "analyzed, no nuggets found" is a real answer, not a silence.
  • Per-source counts and spend: the Sources table on the ops page (row youtube_manual).
